# El tecnico

Un videojuego web estilo "swipe" centrado en la gestión de un club de fútbol en Argentina.
Asume el rol de Director Técnico, toma decisiones binarias sobre el club y lidia con las consecuencias en las finanzas, el vestuario, la dirigencia y los hinchas.

## Instalación y Ejecución

1. Instalar las dependencias:
   ```bash
   npm install
   ```

2. Ejecutar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

## Stack Tecnológico

- React 19
- Vite 8
- Zustand 5
- Framer Motion 13
- Vanilla CSS
